# Noble Finances

Landing page responsiva para uma empresa fictícia de contabilidade e consultoria financeira. O projeto foi desenvolvido a partir de um layout do Figma e finalizado com foco em semântica, acessibilidade e interações simples em JavaScript.

![Preview do projeto Noble Finances](./assets/imagens/preview.png)

## Funcionalidades

- Menu responsivo para dispositivos móveis
- Navegação por âncoras entre as seções
- Cards de serviços adaptáveis a diferentes telas
- Depoimentos atualizados dinamicamente
- Formulário com validação no navegador
- Mensagens de erro acessíveis
- Preferência de redução de movimento respeitada

## Tecnologias

- HTML5 semântico
- CSS3
- JavaScript
- Flexbox e CSS Grid
- Mobile First

## Como executar

Clone o repositório:

```bash
git clone https://github.com/Gabriel707Alves/Noble-Finances.git
```

Depois, abra o arquivo `index.html` no navegador. Para uma experiência melhor durante o desenvolvimento, também é possível usar a extensão Live Server no VS Code.

## Aprendizados

Este projeto foi usado para praticar:

- Organização de HTML com elementos semânticos
- Criação de layouts responsivos com abordagem mobile first
- Manipulação do DOM e eventos
- Uso de `data-*` para selecionar conteúdo dinâmico
- Validação de formulário com a Constraint Validation API
- Atributos ARIA e navegação por teclado

## Observação

O formulário é apenas uma demonstração de front-end e não envia dados para um servidor.
